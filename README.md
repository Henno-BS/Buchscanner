Scannen: Die Kamera im Browser liest den EAN-13-Barcode auf der Buchrückseite. Dafür eignet sich die Bibliothek html5-qrcode oder zxing-js. Die native BarcodeDetector-API gibt es nur auf Android-Chrome, daher ist eine Bibliothek sicherer.
Titel und Autor: Die Open Library API (openlibrary.org/api/books?bibkeys=ISBN:…&format=json&jscmd=data) ist frei und braucht keinen Schlüssel. Als Fallback kann die Google Books API (googleapis.com/books/v1/volumes?q=isbn:…) dienen, weil bei deutschen Büchern manchmal Treffer fehlen.
Datei: Pro Scan eine Zeile ISBN;Titel;Autor in einer Liste. Am Ende folgt der Export als .txt oder .csv über Download oder Teilen-Menü. Zwischendurch wird die Liste im localStorage gespeichert, damit nichts verloren geht. Direkt in eine Datei auf dem Handy schreiben kann der Browser nicht fortlaufend, vor allem nicht unter iOS.
